    A7

    Lucas–Kanade Least Squares

    Verified · Session G · CV14-15 §03-04

    Session G · 01:16:03

    Constraint equation Ixu + Iyv + It = 0 — one equation, two unknowns (aperture problem). Assume a K×K window shares the same (u,v).

  • 5×5 window → 25 equations, 2 unknowns → stack as A·d = b.

  • Over-determined, no exact solution → least-squares normal equations: AᵀA·d = Aᵀb.

  • AᵀA = 2nd-moment matrix = [[ΣIx², ΣIxIy],[ΣIxIy, ΣIy²]] — identical to the Harris corner matrix.

  • Solvable only when AᵀA is invertible and both eigenvalues are large.

    • λ₁, λ₂RegionFlow
    Both smallFlatUntrackable — no gradient information
    One large, one smallEdgeAperture problem — only normal flow
    Both largeCornerTrackable — good feature to track
    Answerd = (AᵀA)⁻¹Aᵀb, valid at corners only — hence Harris / Shi-Tomasi "good features to track" precede LK, rather than tracking random pixels.
    Exact match

    CV_Session14-15_WorldClass.html:507-518 states this identically: "assume a small window of neighboring pixels shares the same (u,v)... M = Σ[[Ix²,IxIy],[IxIy,Iy²]]... same matrix used by the Harris corner detector," with the identical three-way eigenvalue classification table.

    B1

    Optical Flow — Normal Flow from Brightness Constancy

    EC3 · Q1 3 marks

    "In optical flow, using the brightness constancy equation Ix·u + Iy·v + It = 0, calculate the motion vectors u and v for a pixel with the following values: Ix=20, Iy=30, and It=15. Assume a 2×2 window and the least-squares solution. Explain your solution."

  • All 4 pixels of the 2×2 window share the same (Ix,Iy,It) → all 4 constraint rows are identical: A = [[20,30],[20,30],[20,30],[20,30]], b = [-15,-15,-15,-15].

  • Normal equations: AᵀA = [[1600,2400],[2400,3600]] — this is rank-1 (singular), since every row is identical. The aperture problem is not resolved by repeating the same equation four times.

  • With AᵀA singular, take the minimum-norm least-squares solution of the single distinct equation 20u + 30v = −15: d = Aᵀ(AAᵀ)⁻¹b = (Ix,Iy)·(−It)/(Ix²+Iy²).

  • u = 20×(−15)/1300 = −300/1300 ≈ −0.231. v = 30×(−15)/1300 = −450/1300 ≈ −0.346.

  • This is the normal flow — magnitude |It|/√(Ix²+Iy²) = 15/√1300 ≈ 0.416, direction along −(Ix,Iy).

    • Answeru ≈ −0.231, v ≈ −0.346 (normal-flow component only).
    Explain-your-solution part

    Because the window's gradient is uniform, the 2×2 window contributes no new directional information — the aperture problem is not resolved by window size alone; it requires pixels with genuinely different gradient directions (a corner). What's computed here is the perpendicular-to-edge component only; the along-edge component stays undetermined. This directly mirrors A7's eigenvalue test: a rank-1 AᵀA here is the algebraic signature of an "edge" (one non-zero eigenvalue), not a "corner."

    Gaussian Low-Pass Kernel, σ=2

    EC3 · Q5 2 marks

    "Obtain the 3×3 Gaussian LPF kernel with σ=2."

    G(x,y) = 1/(2πσ²) · e^(−(x²+y²)/(2σ²)), x,y ∈ {−1,0,1}, σ=2 Unnormalized: center(0,0)→e⁰=1.000 · edge(dist²=1)→e^(−1/8)=0.8825 · corner(dist²=2)→e^(−2/8)=0.7788 Sum = 4(0.7788) + 4(0.8825) + 1.000 = 7.6452 → divide every cell by this to normalize
    Normalized 3×3 kernel (Σ = 1.00)
    0.1018 0.1154 0.1018 0.1154 0.1308 0.1154 0.1018 0.1154 0.1018
    AnswerCorner weight 0.1018, edge weight 0.1154, center weight 0.1308 — nearly flat because σ=2 is wide relative to a 3×3 window (a tighter σ=0.5 would concentrate far more weight at the center).
    B5

    Zero-Crossings of the Second Derivative

    EC3 · Q5 2+1+1 marks

    "Consider an image with a signal with two steps [values a→b at x₁, b→c at x₂]. Show the zero crossings in the second derivative [2M]. Draw them with the image [1M]. What do they signify? [1M]"

  • First derivative of a step edge is an impulse (spike) at the step location — one spike at x₁, one at x₂.

  • Second derivative of a step is a positive/negative impulse pair straddling each step — it crosses zero exactly at x₁ and at x₂, sitting between the pair.

  • Signification: zero crossings of the second derivative mark the exact locations of intensity discontinuities (edges) — the core principle behind Laplacian-of-Gaussian (LoG) edge detection.

    • AnswerZero crossings occur precisely at x₁ and x₂ — they locate the edges, independent of the step heights a,b,c.
    B6

    Identify the 3×3 Filter

    EC3 · Q5 2 marks

    "Consider the following 3×3 filter. In two statements, explain its purpose."

    Given kernel
    [ 1 2 1 ] [ 0 0 0 ] [ -1 -2 -1 ]
    AnswerThis is a Sobel-style horizontal-edge (vertical-gradient) operator — sign-flipped Sobel Gy. It weights the top row positive and bottom row negative, so it responds strongly wherever intensity changes moving down the image, i.e. it detects horizontal edges while being insensitive to vertical ones (the all-zero middle row and symmetric ±(1,2,1) weighting cancel out uniform regions and horizontal gradients).

    C2

    Harris Corner Detection — Eigenvalues

    New 5 marks

    "A window has four gradient samples (Ix,Iy): (2,1), (1,2), (3,1), (1,3). Compute the second-moment matrix M, its eigenvalues, and the Harris response R (k=0.04). Classify the point."

  • ΣIx² = 4+1+9+1 = 15. ΣIy² = 1+4+1+9 = 15. ΣIxIy = 2+2+3+3 = 10.

  • M = [[15,10],[10,15]]. trace(M) = 30. det(M) = 15×15 − 10×10 = 125.

  • Eigenvalues: λ = trace/2 ± √((trace/2)² − det) = 15 ± √(225−125) = 15 ± 10 → λ₁=25, λ₂=5.

  • Both eigenvalues large (relative to noise floor) → corner candidate, confirm with Harris response.

  • R = det(M) − k·trace(M)² = 125 − 0.04×900 = 125 − 36 = 89.

    • Answerλ₁=25, λ₂=5, R=89 > 0 with large min(λ) → strong corner. (R≈0 would mean flat; R<0 would mean edge.)
    Ties directly to A7

    Same M = [[ΣIx²,ΣIxIy],[ΣIxIy,ΣIy²]] used for Lucas-Kanade trackability — a Harris "corner" here is exactly the "both eigenvalues large" case that makes LK solvable in A7's table.
